# MAX Patcher documentation

Guides for MAX Patcher, an independent Android patcher forked from Morphe Manager, and for
MAX Patches, its patch collection.

| Document | What it answers |
|---|---|
| [INSTALL.md](INSTALL.md) | How to install and set up MAX Patcher |
| [COMPATIBILITY.md](COMPATIBILITY.md) | Which app versions and patches actually work, and the evidence |
| [BUILDING.md](BUILDING.md) | How to build the app, the engine and the patches from source |
| [ARCHITECTURE.md](ARCHITECTURE.md) | How the pieces fit together |
| [PATCH_DEVELOPMENT.md](PATCH_DEVELOPMENT.md) | How to write or fix a patch |
| [TROUBLESHOOTING.md](TROUBLESHOOTING.md) | What to do when a patch or an install fails |
| [CONTRIBUTING.md](CONTRIBUTING.md) | How to contribute |
| [SECURITY.md](SECURITY.md) | How to report a vulnerability, and what this project will never ask for |
| [NOTICE](NOTICE) | Upstream attribution and the list of changes |

## Status

Development. **There is no release yet.** No APK has been built or installed, so nothing here claims
a working build; `COMPATIBILITY.md` says what has and has not been verified.
